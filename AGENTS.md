# Development & Git Guidelines for Hena Masr

## Critical Rules:
1. **Major Updates & Builds**:
   - Whenever any major feature or update is built or modified, always:
     1. Update `Hena Masr App/README.md` to document the changes and new status.
     2. Commit the changes to Git with a clear, descriptive commit message in **English** (e.g. `feat: add full 15-language support and app main demo`).
